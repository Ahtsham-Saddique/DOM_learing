# DOM Learning Project

This project contains simple practice examples of **JavaScript DOM Manipulation**.
It is meant to help beginners understand how to select, modify, and append HTML elements dynamically using JavaScript.

---

## 📂 Files Included

* **index.html** → The main HTML file that displays headings and divs.
* **style.css** → Adds basic styles for `.box` elements (height, width, border, background-color).
* **script2.js** → Contains JavaScript code for DOM manipulation.

---

## 📚 Concepts Covered

1. **Selecting elements**

   * Using `document.getElementsByClassName()`
   * Using `document.querySelector()`

2. **Looping through elements**

   * Converting HTMLCollection to Array with `Array.from()`
   * Using `for...of` loop to update multiple elements

3. **Modifying text**

   * Updating `innerText` of elements
   * Appending custom text to headings

4. **Styling elements**

   * Adding CSS for `.box` divs

---
